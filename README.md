# Metal Tools — web demo

Web de Metal Tools (Arroyito, Córdoba): aparejos eléctricos, punzonadoras y removedoras de cintas de frenos.
HTML + CSS + JS vanilla, sin build. Se abre con doble clic en `index.html`.

## Editar contenido
Todo vive en `data.js` (objeto `CONFIG`): contacto, horarios, productos, specs, textos y colores.
Las imágenes están en `img/` (nombres en minúscula, sin tildes).

## Pendiente del cliente
- Fichas técnicas de punzonadora y removedora (capacidad, potencia, medidas) — marcado en `data.js`
- Link de Facebook y email (campos vacíos en `data.js`; no se muestran hasta completarlos)
- Fotos propias en alta calidad (las actuales salen de capturas del catálogo y del Instagram)
- Dominio final: actualizar `og:url` y `url` del JSON-LD en `index.html`
- Que el cliente tenga el Perfil de Empresa de Google completo con el link a la web

Web hecha por [Vigolo Web Studio](https://vigolowebstudio.com).
